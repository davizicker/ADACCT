# Créditos da captura de movimento

Os arquivos `cmu_*.bvh` vêm do **banco de captura de movimento da CMU (Carnegie Mellon University Graphics Lab)**, na conversão para BVH feita por Bruce Hahne (cgspeed.com), cópia em https://github.com/una-dinosauria/cmu-mocap.
Texto de agradecimento pedido pela CMU (colocar nos créditos do jogo):

> "The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217."

Termos (resumo do `READMEFIRST.txt` da conversão): os dados podem ser usados livremente, inclusive em produtos comerciais; **não é permitido revender os dados em si**, nem convertidos. Aqui eles ficam só dentro das animações do jogo, retargetadas ao seu esqueleto.
Clipes usados: 02_01 (andar), 02_03 (correr), 20_08 (marcha de zumbi), 07_04 (andar lento), 08_11 (passada larga).
